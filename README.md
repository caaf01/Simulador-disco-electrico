# imulador-disco-electrico
Simulador 3D interactivo de electrostática desarrollado con Three.js, KaTeX y Chart.js. Modifica carga, radio y sensor en tiempo real para visualizar campos, potenciales y anillos diferenciales de un disco cargado. Incluye gráficas dinámicas de V(x) y exportación de datos a CSV para análisis académico.
